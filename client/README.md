# Data Entry Portal - Client

Modern React-based data entry portal with Material-UI, Framer Motion, and Three.js.

## Installation

```bash
npm install
```

## Configuration

Create a `.env` file:
```
REACT_APP_API_URL=http://localhost:5000/api
```

## Development

```bash
npm start
```

Runs on http://localhost:3000

## Build

```bash
npm run build
```

## Features

- ✅ Modern UI with Material-UI
- ✅ Smooth animations with Framer Motion
- ✅ 3D background with Three.js
- ✅ Form validation
- ✅ Responsive design
- ✅ Green theme (#00FF66)
